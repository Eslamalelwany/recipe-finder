## 📌 About the Project

**Recipe Finder** is a front-end-only React application for discovering and browsing recipes. It was built to practice component architecture, search/filter logic, and responsive UI design — all handled entirely on the client side, no backend required.

---

## ✨ Features

- 🔍 Search and browse recipes
- 🍽️ View recipe details (ingredients, steps, etc.)
- 📱 Fully responsive design (mobile, tablet, desktop)
- ⚡ Fast, lightweight client-side experience

## 🚀 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v16 or higher)
- npm (comes with Node.js)

```bash
node -v
npm -v
```

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/Eslamalelwany/recipe-finder.git
   ```
2. **Navigate into the project directory**
   ```bash
   cd recipe-finder
   ```
3. **Install dependencies**
   ```bash
   npm install
   ```
4. **Run the development server**
   ```bash
   npm start
   ```
5. Open [http://localhost:3000](http://localhost:3000) in your browser 🎉

---

## 💻 Usage

Once running, you can:

- Browse the list of available recipes
- Search for a specific recipe
- Click on a recipe to view full details
